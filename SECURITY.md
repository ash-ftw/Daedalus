# Security Policy

## Reporting Vulnerabilities

If you identify a security issue in Daedalus, please report it privately:

- Email: security@daedalus.local (or create a private security advisory on GitHub: https://github.com/ash-ftw/Daedalus/security/advisories)
- Please include steps or proof-of-concept demonstrating the issue.

Please do not open public issues for sensitive security vulnerabilities until they have been addressed.
